# 데이터 안내

## raw

- `올리브영_크림240개_상품명_전성분.csv`: 상품명과 전성분 원본

## interim

- `전성분_표준화_최종.csv`: 원료명 표준화 및 농도 정보 결합 결과
- `V1_전체성분_원핫인코딩.csv`: 전체 성분 멀티핫 특징
- `V2_선택성분_목록.csv`: V2 선택 성분과 빈도 기준
- `V2_선택성분_원핫인코딩.csv`: 선택 성분 멀티핫 특징
- `V3_성분기능군_개수.csv`: 성분 기능군별 count 특징
- `V3_성분기능군_매핑표.csv`: 표준 성분과 기능군의 매핑 결과

- `V4_문헌기반_성분조합.csv`: 문헌·도메인 규칙 특징
- `V4_특징설명.csv`: V4 조합 특징의 정의와 해석
- `V5_제품명_강조주제.csv`: 제품명 강조 테마 특징
- `V5_제품별_강조주제.csv`: 제품별 강조 주제 분류 결과
- `V5_주제별_성분비율.csv`: 강조 주제별 성분 출현 비율
