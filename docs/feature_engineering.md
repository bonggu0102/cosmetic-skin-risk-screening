# Feature Engineering

## V1 — 전체 성분 멀티핫

정규화된 `canonical_name`을 기준으로 제품에 성분이 존재하면 1, 없으면 0으로 표현합니다. 전체 성분 정보를 보존하지만 특징 차원이 크고 희소합니다.

## V2 — 빈도 기반 선택 성분 멀티핫

성분명을 정규화하고 제품 내부 중복을 제거한 후 제품 출현 빈도를 계산합니다. 8개 이상 제품에 등장하며 전체 제품의 80%를 초과하지 않는 성분만 선택합니다.

## V3 — 성분 기능군 count

성분을 보습, 진정, 장벽 등 기능군에 매핑하고 제품별 기능군 성분 개수를 특징으로 사용합니다. 매핑되지 않은 성분은 별도 검토 목록으로 관리합니다.

## V4 — 논문·도메인 지식 기반 조합

V4는 논문 내용을 텍스트로 입력한 것이 아니라, 문헌에서 확인한 피부유형과 성분의 관계를 계산 가능한 규칙으로 바꾼 특징입니다. `전성분_표준화_최종.csv`의 성분 정보와 V3 기능군 개수를 사용해 다음 값을 생성합니다.

- 가벼운 에스터, 휘발성·비휘발성 실리콘, 식물성 오일, 왁스·버터, 에센셜 오일 등 처방 구성별 성분 수
- 나이아신아마이드, 판테놀, 세라마이드, 살리실릭애씨드 등의 포함 여부와 전성분 내 표기 순서
- 세라마이드·콜레스테롤·지방산 등 주요 장벽 성분의 포함 여부

이 값을 피부유형별 규칙과 결합합니다.

| 피부유형 | 규칙 예시 |
|---|---|
| 건성·약건성 | 보습제·유연제·밀폐제가 함께 구성된 정도, 세라마이드·콜레스테롤·지방산의 장벽 조합 |
| 민감성 | 판테놀 또는 나이아신아마이드와 장벽·진정 성분의 조합, 향료·산 성분·에센셜 오일 부담 |
| 지성 | 나이아신아마이드의 표기 순서, 무거운 오일성 처방과 가벼운 실리콘·에스터 처방의 정도 |
| 트러블성 | 나이아신아마이드+세라마이드, 살리실릭애씨드+장벽 성분 조합, 장벽 보완 없는 산 성분 사용 |

각 규칙은 해당 피부유형에서만 값이 생기며, 성분 개수가 많아질수록 값이 무한히 커지지 않도록 0~1에 가까운 점수로 변환합니다. 문헌 근거가 있는 규칙에는 가중치를 적용해 `support`, `caution`, 두 점수가 동시에 큰 `conflict` 점수도 생성합니다. 상수이거나 값이 완전히 같은 중복 변수는 제거한 뒤 최종 V4 특징 32개를 사용합니다.

이 규칙은 특정 성분의 임상 효과를 확정하는 기준이 아니라, 단순 원-핫 인코딩에서 표현하기 어려운 피부유형별 성분 구성을 모델에 전달하기 위한 Feature Engineering입니다.

## V5 — 제품명 강조 테마

제품명에서 보습, 진정, 장벽 등 강조된 효능 테마를 탐지해 특징으로 사용합니다.

## 최종 특징 세트

- V1 계열: 전체 성분 V1에 V3·V4·V5 결합
- V2 계열: 선택 성분 V2에 V3·V4·V5 결합

두 특징 세트의 성능을 비교함으로써 전체 성분을 사용할 때와 빈도 기반으로 차원을 줄였을 때의 차이를 평가합니다.
