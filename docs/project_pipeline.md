# 프로젝트 파이프라인

## 1. 데이터 수집

올리브영 크림 상품의 상품 정보, 전성분, 피부타입·피부톤별 리뷰를 수집합니다.

## 2. 전성분 전처리

상품별 전성분 문자열을 long 형식으로 변환하고 성분명을 정규화합니다. 식약처 성분 마스터와 매칭하며 애매한 결과는 별도 로그로 관리합니다.

## 3. Feature Engineering

전체 성분, 선택 성분, 기능군, 논문 기반 조합, 제품명 강조 테마의 다섯 가지 관점으로 특징을 생성합니다.

## 4. 감성분석

리뷰를 긍정·부정·애매로 분류하고 배송 관련 불만은 제품 자체의 부정 평가에서 제외합니다.

## 5. 모델링

리뷰 감성 결과를 제품·피부타입 단위로 집계하고, 성분 특징과 결합하여 부정 리뷰 고위험군을 예측합니다.

## 6. 평가

학습 데이터와 테스트 데이터를 분리해 확률 예측, 분류 결과 및 정답 여부를 저장합니다. 테스트 행별 결과는 `reports/metrics/테스트_예측결과.csv`에 있습니다.
